# saltscan-site

Website for [Salt Scan](https://github.com/TrabelsiAchraf/SaltScan), the iOS app that checks the salt and sodium in food.

Published by GitHub Pages from `main`, served at <https://trabelsiachraf.com/saltscan-site/>.
